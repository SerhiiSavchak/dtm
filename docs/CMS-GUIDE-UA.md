# Адмінка сайту DTM

Адреса: `/admin` на сайті DTM.

## Як увійти

1. Відкрийте `/admin`.
2. Увійдіть через Google, GitHub або email — той спосіб, який вам підключили.
3. Якщо нічого не просить і одразу відкривається список — ви вже були залогінені в цьому браузері.

Зміни на сайті з’являються після **Publish**. Поки документ у чернетці (Draft), відвідувачі сайту їх не бачать.

- **Draft** — збережено в адмінці, на сайті ще ні.
- **Publish** — показати на сайті.

## Як змінити роботу

1. **Наші роботи**.
2. Відкрийте потрібну картку.
3. Змініть назву, тип, площу, опис, обкладинку або галерею.
4. **Publish**.

Англійська вкладка не обов’язкова. Якщо порожня — на англійській версії сайту буде український текст.

## Як створити роботу

1. **Наші роботи** → створити нову роботу.
2. Назва, тип об’єкта, площа, опис.
3. Обкладинка (фото для списку на головній).
4. Галерея — кілька фото.
5. За бажанням: тип робіт, термін, рік.
6. **Publish**.

Службові адреси й технічні поля створюються самі. Їх не треба заповнювати.

## Як завантажити фото

У полі **Обкладинка** або в елементі галереї натисніть область завантаження й оберіть файл. Можна посунути важливу частину кадру в стандартному вікні обрізання.

## Як змінити порядок фото

У **Галереї** перетягніть картки. Перше фото відкривається першим у вікні проєкту. Потім **Publish**.

## Як змінити порядок робіт

У списку **Наші роботи** перетягніть рядки. Верхній (або перший у стрічці) — головна велика картка на сайті. Потім зачекайте публікації / **Publish**, якщо редактор просить.

## Як додати фото або відео в «Об’єкти зараз у роботі»

1. **Об’єкти зараз у роботі** → **Усі фото та відео**.
2. Створіть запис.
3. Назва для адмінки (на сайті не видно).
4. Обов’язкове фото. Відео — за бажанням.
5. **Publish**.

## Як вибрати 4 матеріали на головній

1. **Об’єкти зараз у роботі** → **4 матеріали на головній**.
2. Оберіть рівно 4 вже завантажені кадри.
3. Порядок у списку = порядок панелей зліва направо.
4. **Publish**.

Не дублюйте той самий кадр двічі.
