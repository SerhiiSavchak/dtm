# Чекліст QA — CMS DTM

Робочий датасет: `development`. Production не чіпати.

## Auth

- [ ] Звичайний браузер розробника: `/admin` може відкритися вже залогіненим у Sanity.
- [ ] Режим інкогніто: `/admin` показує вхід Google / GitHub / email.
- [ ] Без акаунта Sanity не видно списку робіт і не можна публікувати.
- [ ] Вхід дозволеним користувачем відкриває «Наші роботи».

## Портфоліо

- [ ] Створити тимчасову роботу «Тестова квартира», обкладинка + ≥2 фото, Publish.
- [ ] Перейменувати на «Тестова квартира NEW», Publish — на сайті той самий проєкт, не дубль.
- [ ] Змінити порядок фото перетягуванням.
- [ ] Змінити порядок робіт у списку — порядок на сайті той самий.
- [ ] Перевірити головну й вікно проєкту.
- [ ] Видалити тестову роботу.

## Об’єкти зараз у роботі

- [ ] Створити тимчасове фото/відео з «Назва для адмінки».
- [ ] Воно з’являється в «Усі фото та відео».
- [ ] Підставити його в «4 матеріали на головній», Publish, перевірити головну й повний перегляд.
- [ ] Перейменувати назву для адмінки — панелі на сайті не «губляться».
- [ ] Повернути попередні 4 матеріали.
- [ ] Видалити тестовий кадр (якщо він у четвірці — спочатку прибрати з дошки).
