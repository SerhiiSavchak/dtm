# Чекліст передачі проєкту клієнту

Нічого з цього списку ще не передано. Секрети в документ не записувати.

| Сервіс | Зараз | Має стати | Що зробити пізніше |
| --- | --- | --- | --- |
| Sanity (CMS) | Проєкт і доступ у розробника | Організація / логін власника DTM | Запросити клієнта, забрати зайві ролі. Датасет production поки не чіпати |
| Git (код) | Репозиторій розробника | Репозиторій / org клієнта або спільний org | Transfer або fork + нові deploy keys |
| Хостинг (Vercel або аналог) | Акаунт розробника | Акаунт клієнта | Перенести проєкт або створити новий і підключити git |
| Домен / DNS | Обліковий запис, де куплено домен | Клієнт | Змінити контакти реєстратора, оновити NS якщо треба |
| Telegram-бот заявок | Бот і chat id у env розробника | Бот клієнта або спільний, chat клієнта | Новий бот або передати токен; оновити `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` |
| Email заявок (Resend, опційно) | Ключ і адреса відправника розробника | Домен клієнта + його Resend | `RESEND_API_KEY`, `LEADS_TO_EMAIL`, `LEADS_FROM_EMAIL` |
| Публічні посилання | Можуть бути дефолти в коді | Посилання клієнта | `NEXT_PUBLIC_TELEGRAM_URL`, `NEXT_PUBLIC_PHONE_URL`, `NEXT_PUBLIC_INSTAGRAM_URL`, `NEXT_PUBLIC_SITE_URL` |
| Sanity Studio | `NEXT_PUBLIC_SANITY_PROJECT_ID`, `NEXT_PUBLIC_SANITY_DATASET` | Той самий проєкт, датасет production після окремої міграції | CORS: localhost + бойовий домен, credentials |
| Analytics / Search Console / Meta Pixel | У репозиторії не підключено | Лише якщо клієнт захоче, без платного обов’язку | Не додавати платні сервіси «за замовчуванням» |

Обов’язкові інфраструктурні платежі, крім продовження домену, не потрібні: Sanity безкоштовний тариф, хостинг на безкоштовному плані, Telegram Bot API без абонплати.

Залежності, які зараз тримаються на розробнику: CMS-доступ, git, хостинг, DNS, Telegram, опційний email. Поки вони не переписані на клієнта, сайт не автономний.
